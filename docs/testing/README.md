# Isolated ATM10 market runtime test

`atm10-market-test.js` is a destructive KubeJS server-script fixture for a **disposable copied ATM10 world and test player only**. It clears selected test-player inventory slots and changes knowledge/EMC. Never enable it in a live instance or world. Its matching `atm10-market-config.json` intentionally sets a diamond-only exchange whitelist, a one-item index basket, and fractional root priors; it is a test configuration, not recommended gameplay settings.

The test clone used ATM10 with the new ProjectE jar. It disabled the original ProjectE jar, ProjectExpansion (which has independent static-price exchange routes), and an unrelated `mct` client addon that crashed during login. Those deviations limit addon coverage. The fixture runs phase 1 on first login, records q=1 and a fractional sale, then requires a complete client/world stop and restart for phase 2. Phase 2 checks persisted q, knowledge and fractional EMC; Tome-only knowledge rejection; SlotOutput purchase; container quick-move buy and physical shift-sell; manual pickup; hotbar swap; and index restoration. It writes `kubejs/market-test-phase.json` and `kubejs/market-test-result.json` in the clone. Remove or rename the script after the test to prevent operations on later logins.

`atm10-market-result.json` records the observed run. The source test world was copied read-only. The live-instance checksum comparison covered exactly 2,388 config files, the two ProjectE-related jars, `instance.cfg`, and `mmc-pack.json` (2,392 files total); it did not cover every mod jar or save. The full private logs and disposable world remain under the sibling `testing/ATM10-Market` directory and are not part of this repository.
